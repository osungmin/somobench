# [BP-ENG-CH-501-004] 냉동기 CH-501 운전·정비 표준서
문서등급: 사내 기술자료 / 개정: Rev.3 / 담당: 설비기술팀

## 1. 정상 운전 기준
냉동기 CH-501의 정상 COP 관리범위는 4.1~4.6이다. 생산부하 80% 기준 소비전력 관리범위는 150~165 kW이다. 냉각수 유량과 응축기 접근온도는 일일점검 항목으로 관리한다.

## 2. COP 저하 시 점검 순서
COP가 3.5 이하로 하락하거나 기준선 대비 15% 이상 저하되면 다음 순서로 점검한다.
1. 냉각수 유량 및 펌프 운전상태 확인
2. 냉각수 입·출구 온도와 응축기 접근온도 확인
3. 스트레이너 및 응축기 튜브 오염 여부 확인
4. 냉매 압력과 냉매량 확인
5. 온도·압력 센서 교정상태 확인

냉각수 유량이 정상인데 응축기 접근온도가 상승하고 소비전력이 함께 증가하는 경우 응축기 열교환 성능 저하 또는 오염을 우선 점검한다.

## 3. 권고 조치
응축기 오염이 확인되면 튜브 세척 후 동일 부하 조건에서 COP와 소비전력을 재측정한다. 조치 전후 데이터를 최소 2시간 이상 비교하여 개선효과를 확인한다.
