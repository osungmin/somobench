# [BP-ENG-CMP-301-006] 공기압축기 CMP-301 운전·정비 표준서
문서등급: 사내 기술자료 / 개정: Rev.2 / 담당: 유틸리티팀

## 1. 에너지 관리 기준
비생산 시간대에는 압축공기 기저부하를 최소화한다. 생산량 변화가 없는데 압축기 소비전력이 지속되거나 토출압력 회복주기가 짧아지는 경우 누설 또는 불필요한 무부하 운전을 의심한다.

## 2. 누설 점검
1. 비생산 시간대 기저전력 확인
2. 메인 헤더 압력강하 추세 확인
3. 구역별 차단밸브를 순차 점검하여 누설구간 분리
4. 초음파 누설탐지기로 플랜지·피팅·호스·밸브 확인
5. 수리 후 동일 시간대 기저부하 재측정

## 3. 운전 최적화
필요 압력 이상으로 토출압력을 높이지 않으며 복수 압축기 운전 시 부하분담과 시퀀스 제어를 점검한다.
